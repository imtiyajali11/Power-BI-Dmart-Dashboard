# D-Mart Sales Dashboard | Power BI Project

## Project Overview
This project presents an interactive Power BI dashboard built using D-Mart Grocery Sales data to analyze sales performance, customer purchasing patterns, and business insights. The dashboard helps in understanding key metrics and supports data-driven decision making.

## Objectives
- Analyze overall sales performance
- Identify top-performing products and categories
- Track revenue trends and customer behavior
- Understand sales distribution across different dimensions
- Generate actionable business insights

## Dataset Information
The dataset contains retail grocery sales information including:

- Order details
- Product categories
- Sales amount
- Quantity sold
- Customer information
- Profit and revenue metrics
- Date and transaction-related fields

## Dashboard Features
### Key KPIs
- Total Sales
- Total Orders
- Total Profit
- Average Sales
- Quantity Sold

### Visualizations Used
- Sales trend analysis
- Category-wise sales distribution
- Top-selling products
- Revenue contribution analysis
- Interactive filters and slicers
- Comparative charts and KPI cards

## Tools & Technologies Used
- Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)
- Data Modeling
- CSV Dataset

## Project Workflow
1. Data Collection
2. Data Cleaning using Power Query
3. Data Transformation
4. Data Modeling
5. DAX Measures Creation
6. Dashboard Development
7. Insights Generation

## Key Insights
- Identified top-performing product categories
- Analyzed sales patterns and trends
- Found revenue contribution across categories
- Created an interactive business reporting dashboard
